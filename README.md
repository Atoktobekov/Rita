# Daily To-Do

Daily To-Do — русскоязычный планировщик на Flutter для Android и iOS. Планируйте задачи на день, отмечайте выполненное и возвращайтесь к прошлым планам через архив. Приложение работает без аккаунта, задачи и настройки хранятся на устройстве. Автор проекта — **Ади**.

Текущая версия — **0.7.0** (сборка **7**). [Версия в `pubspec.yaml`](pubspec.yaml)

## Планирование

- На вкладке «Сегодня» можно открыть план на сегодня, завтра или любую дату через календарь. Экран «Будущие планы» показывает даты с запланированными задачами.
- Нажмите на карточку, чтобы отметить задачу выполненной. Удерживайте карточку, чтобы изменить название или дату либо удалить задачу. Удаление можно отменить.
- Список можно отфильтровать по статусу. Выполненные задачи перемещаются под незавершённые, а индикатор показывает прогресс выбранного дня.
- Кнопка «Скопировать незавершённые на завтра» создаёт копии всех незавершённых задач выбранного текущего или прошедшего дня. Исходные задачи остаются в истории. Копирование можно отменить, пока все созданные копии остаются в исходном виде.
- В «Архиве» можно редактировать планы прошедших дней. В «Статистике» доступны общий прогресс, текущая серия и график шести прошедших дней в задачах или процентах. Нажмите на столбик, чтобы открыть и отредактировать день.
- Во вкладке «Ачивки» отображаются 13 обычных достижений. Секретное появляется после выполнения его условия. Статистика и достижения рассчитываются по текущим данным и учитывают задачи до сегодняшнего дня включительно.

## Оформление и напоминания

Откройте «Ачивки» → «Настройки». В разделе «Дизайн приложения» доступны **Уют**, **Фокус**, **Искра** и **Лист**. По умолчанию выбран «Уют». Для каждого дизайна можно выбрать светлую или тёмную тему либо следовать настройке устройства. Приложение запоминает оба выбора.

Вечернее напоминание по умолчанию выключено, предустановленное время — **21:30**. При включении приложение запрашивает разрешение на уведомления. Напоминание повторяется ежедневно по местному времени. После смены часового пояса откройте приложение, чтобы обновить расписание.

Уведомления доступны на Android и iOS. На Android энергосбережение может задержать доставку. В репозитории также есть сборочные цели для Web и Windows. На этих платформах планирование уведомлений недоступно.

## Резервные копии

Откройте «Архив» → «Копии задач». Экспорт сохраняет исправные задачи за все даты в JSON-файл. Настройки и изолированные повреждённые записи хранятся отдельно на устройстве. В браузере файл скачивается, а в приложении открывается системный диалог сохранения.

Поддерживается формат `daily-todo-tasks` версии 1. Размер файла ограничен 10 МБ, количество задач — 20 000. При импорте приложение проверяет данные, показывает дату создания копии, количество задач и диапазон дат. После подтверждения задачи из файла заменяют текущие, а предыдущая версия сохраняется автоматически. Восстановление меняет местами текущую и предыдущую версии.

Сохраните JSON-файл отдельно от приложения. Очистка данных приложения или сайта удалит локальные задачи и предыдущую версию.

## Локальный запуск

В рабочем окружении проекта используются **Flutter 3.50.0** и входящий в него **Dart 3.14.0**. Для Android настройте Android SDK и установите NDK **29.0.14206865**. Версии Gradle **9.3.1**, Android Gradle Plugin **9.1.1** и Kotlin **2.4.10** заданы в проекте.

Из корня репозитория выполните команды ниже. Подставьте идентификатор из вывода `flutter devices` вместо `DEVICE_ID`.

```sh
flutter doctor
flutter pub get
flutter devices
flutter run -d DEVICE_ID
```

- Для отладочного APK выполните `flutter build apk --debug`. Для публикации Android-сборки потребуется настроить собственную подпись. Текущая конфигурация `release` использует отладочный ключ. [Настройки Android-сборки](android/app/build.gradle.kts)
- Для iOS нужны macOS, Xcode и CocoaPods. Сборка без подписи — `flutter build ios --no-codesign`. Для установки на iPhone выберите команду разработчика Apple в Xcode.

## Проверки

```sh
flutter analyze
flutter test
```

Тесты охватывают совместимость со старыми данными Hive, импорт и восстановление копий, планирование, смену календарного дня и настройки уведомлений. Доставку уведомлений проверяют отдельно на устройствах Android и iOS.

Для визуальной проверки запустите тест ниже. Он сохраняет снимки основных экранов, настроек и выбора дизайна в `build/qa/`.

```sh
flutter test test/preview_test.dart --dart-define=VISUAL_REVIEW=true
```

## Структура проекта

- [`lib/main.dart`](lib/main.dart) открывает локальное хранилище и связывает зависимости.
- В [`lib/domain/`](lib/domain/) находятся модели и сценарии работы с задачами, статистикой и напоминаниями. Этот слой независим от Flutter и Hive.
- В [`lib/data/`](lib/data/) находятся репозитории Hive CE, формат JSON-копий и планировщик уведомлений.
- В [`lib/presentation/`](lib/presentation/) находятся экраны, контроллеры и палитры четырёх дизайнов.

Задачи и предыдущая версия хранятся в снимке `tasks_v2`, настройки — в `settings_v1`. При первом запуске со старыми данными приложение копирует задачи из `tasks_v1` в новый формат. Повреждённые записи изолируются, чтобы исправные задачи оставались доступны. Даты задач хранятся как локальные календарные даты (`YYYY-MM-DD`).

Ранние релизы 0.1.0 и 0.2.0 описаны в [истории изменений](CHANGELOG.md).
